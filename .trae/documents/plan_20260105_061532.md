# 为所有图表添加具体期数显示

## 1. 问题分析
- 当前所有图表在统计期数为"全部期"时，只显示"全部期"文本
- 需要修改为显示具体的期数，如"全部期(1234期)"
- 有现成的`huo_qu_lottery_results_total()`函数可以获取总期数
- 该函数调用服务器的`/huo_qu_lottery_results_total`接口

## 2. 解决方案
### 2.1 核心修改点
- 为每个图表绘制函数添加总期数获取逻辑
- 修改统计期数文本生成逻辑
- 确保在各种场景下都能正确显示

### 2.2 具体实现步骤
1. **修改图表绘制函数**：
   - 在每个图表绘制函数中添加总期数获取逻辑
   - 当`periodValue`为"all"时，调用`huo_qu_lottery_results_total()`获取总期数
   - 生成格式化的统计期数文本，如"全部期(1234期)"

2. **修改相关页面**：
   - `dao_shu_3_qi_san_qiu_zu_he.html`
   - `dao_shu_2_qi_san_qiu_zu_he.html`
   - `dao_shu_5_qi_liang_qiu_zu_he.html`
   - `dao_shu_4_qi_liang_qiu_zu_he.html`
   - `dao_shu_3_qi_liang_qiu_zu_he.html`
   - `dao_shu_2_qi_liang_qiu_zu_he.html`
   - `sha_hao_fen_xi.html`
   - `san_qiu_fen_xi.html`
   - 其他涉及图表的页面

3. **修改主题切换和排序切换逻辑**：
   - 确保在主题切换时重新绘制图表时也能显示正确的总期数
   - 确保在排序切换时重新绘制图表时也能显示正确的总期数

## 3. 技术实现
### 3.1 图表绘制函数修改
```javascript
// 绘制统计期数信息
ctx.fillStyle = isDarkTheme ? '#ccc' : '#333';
ctx.font = '12px Arial';
ctx.textAlign = 'left';
ctx.textBaseline = 'bottom';

let periodText;
if (periodValue === 'all') {
  // 获取总期数
  const totalPeriods = await huo_qu_lottery_results_total();
  periodText = `全部期(${totalPeriods}期)`;
} else {
  periodText = `最近${periodValue}期`;
}
ctx.fillText(`统计期数: ${periodText}`, padding.left + 5, padding.top + 15);
```

### 3.2 全局变量缓存
为了避免重复调用API，可以添加一个全局变量来缓存总期数：
```javascript
let globalTotalPeriods = null;

// 获取总期数，带缓存
async function getTotalPeriods() {
  if (globalTotalPeriods) {
    return globalTotalPeriods;
  }
  const total = await huo_qu_lottery_results_total();
  globalTotalPeriods = total;
  return total;
}
```
