# 修复浏览器最小化时回测暂停的问题

## 问题原因
当浏览器窗口最小化或页面不可见时，浏览器会降低或暂停 `requestAnimationFrame` API 的执行频率，以节省系统资源。代码中大量使用了 `requestAnimationFrame` 来更新进度条和界面元素，导致回测流程在浏览器最小化时被阻塞。

## 解决方案
移除所有 `requestAnimationFrame` 的使用，直接进行 DOM 更新操作，确保回测流程不受浏览器可见性影响。

## 修复步骤

1. **修改 `updateProgress` 函数**
   - 将 `requestAnimationFrame` 替换为直接 DOM 更新
   - 确保 Promise 立即 resolve，不等待浏览器重绘

2. **修复进度条显示逻辑**
   - 移除显示进度条时使用的 `requestAnimationFrame`
   - 直接设置进度条的样式和内容

3. **修复进度条隐藏逻辑**
   - 移除隐藏进度条时使用的 `requestAnimationFrame`
   - 直接隐藏进度条元素

4. **修复其他使用 `requestAnimationFrame` 的地方**
   - 检查并修复所有文件中使用 `requestAnimationFrame` 的代码
   - 确保所有 DOM 更新操作都直接执行

## 影响范围
- `xia_qi_hou_qu_kai_jiang_yu_ce.html`
- `xia_qi_kai_jiang_yu_ce.html`
- 其他可能使用了相同回测逻辑的页面

## 预期效果
修复后，回测过程将在浏览器最小化时继续执行，不受浏览器可见性影响，同时保持正常的进度更新功能。
