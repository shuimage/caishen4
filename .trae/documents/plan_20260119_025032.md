# 实现回测结果数据库存储功能

## 1. 问题分析
- 前端代码中调用了 `bao_cun_hui_ce_jie_guo` 接口来保存回测结果
- 后端代码中没有实现这个接口，导致回测结果无法存储到数据库
- 同时也需要实现 `huo_qu_hui_ce_jie_guo` 接口来查询回测结果

## 2. 解决方案

### 2.1 创建回测结果表
- 在数据库中创建一个 `backtest_results` 表，用于存储回测结果
- 表结构包括：id、cache_key、backtest_results（JSON类型）、current_period、created_at

### 2.2 实现后端接口
- 在 `服务器.js` 中添加 `bao_cun_hui_ce_jie_guo` 接口（POST），用于保存回测结果
- 在 `服务器.js` 中添加 `huo_qu_hui_ce_jie_guo` 接口（GET），用于查询回测结果

### 2.3 接口实现细节

#### 2.3.1 保存回测结果接口（POST /bao_cun_hui_ce_jie_guo）
- 接收参数：cache_key、backtest_results、current_period
- 检查参数是否完整
- 插入或更新数据库记录
- 返回保存结果

#### 2.3.2 查询回测结果接口（GET /huo_qu_hui_ce_jie_guo）
- 接收参数：cache_key
- 根据cache_key查询数据库
- 返回回测结果

### 2.4 代码实现

1. **修改数据库配置**：确保数据库支持JSON类型（如果使用MySQL 5.7+，可以使用JSON类型；如果使用其他数据库，可能需要调整）

2. **添加表结构**：
```sql
CREATE TABLE IF NOT EXISTS backtest_results (
  id INT AUTO_INCREMENT PRIMARY KEY,
  cache_key VARCHAR(255) NOT NULL UNIQUE,
  backtest_results JSON NOT NULL,
  current_period VARCHAR(20) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

3. **实现保存接口**：
```javascript
app.post('/bao_cun_hui_ce_jie_guo', async (req, res) => {
  try {
    const { cache_key, backtest_results, current_period } = req.body;
    if (!cache_key || !backtest_results || !current_period) {
      return res.status(400).json({ success: false, message: '缺少必要参数' });
    }
    
    // 检查是否已存在该cache_key的记录
    const checkSql = 'SELECT id FROM backtest_results WHERE cache_key = ?';
    const checkResult = await query(checkSql, [cache_key]);
    
    if (checkResult.length > 0) {
      // 更新现有记录
      const updateSql = 'UPDATE backtest_results SET backtest_results = ?, current_period = ? WHERE cache_key = ?';
      await query(updateSql, [JSON.stringify(backtest_results), current_period, cache_key]);
    } else {
      // 插入新记录
      const insertSql = 'INSERT INTO backtest_results (cache_key, backtest_results, current_period) VALUES (?, ?, ?)';
      await query(insertSql, [cache_key, JSON.stringify(backtest_results), current_period]);
    }
    
    res.json({ success: true, message: '回测结果保存成功' });
  } catch (error) {
    console.error('保存回测结果失败:', error);
    res.status(500).json({ success: false, message: '保存回测结果失败' });
  }
});
```

4. **实现查询接口**：
```javascript
app.get('/huo_qu_hui_ce_jie_guo', async (req, res) => {
  try {
    const { cache_key } = req.query;
    if (!cache_key) {
      return res.status(400).json({ success: false, message: '缺少必要参数' });
    }
    
    const sql = 'SELECT backtest_results FROM backtest_results WHERE cache_key = ?';
    const result = await query(sql, [cache_key]);
    
    if (result.length > 0) {
      res.json({ success: true, data: JSON.parse(result[0].backtest_results) });
    } else {
      res.json({ success: false, message: '未找到回测结果' });
    }
  } catch (error) {
    console.error('查询回测结果失败:', error);
    res.status(500).json({ success: false, message: '查询回测结果失败' });
  }
});
```

5. **确保接口被正确注册**：将接口添加到服务器.js文件中
