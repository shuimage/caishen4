# 优化推荐买号合集功能计划

## 1. 问题分析
当前的推荐买号合集功能已经实现了基本逻辑，但存在以下问题：
- 页面加载完成后，如果表格中已有数据，合集不会自动更新
- 函数调用时机不够全面
- 数据提取逻辑可以进一步优化

## 2. 改进方案

### 2.1 添加页面初始化调用
- 在页面加载完成后调用`updateBuyNumbersCollectionNewest`函数
- 确保初始状态下合集数据正确

### 2.2 优化数据提取逻辑
- 结合两种提取方式：
  - 继续使用正则表达式提取文本中的数字
  - 同时支持从`.red-ball`元素中提取号码
- 提高数据提取的可靠性，适应不同的渲染方式

### 2.3 确保函数在所有数据更新时被调用
- 检查所有可能更新表格数据的位置
- 确保在任何数据更新后都调用合集更新函数

### 2.4 添加调试信息
- 添加必要的console.log语句，便于调试
- 提高代码的可维护性

## 3. 具体实现步骤

1. **在页面初始化时调用**：
   - 找到页面加载完成的事件处理函数
   - 添加`updateBuyNumbersCollectionNewest`函数调用

2. **优化数据提取逻辑**：
   - 修改`updateBuyNumbersCollectionNewest`函数
   - 添加从`.red-ball`元素提取号码的逻辑
   - 合并两种方式提取的号码

3. **检查调用时机**：
   - 确保在`renderDetailDataNewest`函数结束后调用
   - 检查是否有其他地方需要调用

4. **测试验证**：
   - 确保在各种情况下合集都能正确显示
   - 验证数据提取的准确性

## 4. 预期效果
- 页面加载完成后，合集自动更新
- 无论表格数据如何渲染，合集都能正确提取所有推荐买号
- 在数据更新时，合集实时更新
- 提高了功能的可靠性和健壮性
