## 问题分析
1. **最新开奖信息的开奖日期显示 undefined**：
   - 原因：`renderLatestDrawInfo` 函数尝试从 `latestDraw.periodTime` 获取日期，但 API 返回的数据中可能没有这个字段
   - 解决方案：使用 `drawDate` 字段代替 `periodTime`

2. **倒数2期和倒数3期卡片中当前回测期号显示 [object Object]**：
   - 原因：`huo_qu_dao_shu_2_qi` 和 `huo_qu_dao_shu_3_qi` 函数返回的是完整的开奖信息对象，而不是期号字符串
   - 解决方案：修改渲染函数，从返回对象中提取期号

3. **倒数2期和倒数3期卡片中下一期/下下下期期号显示 NaN**：
   - 原因：当前回测期号为对象，`parseInt` 转换后为 NaN，导致后续计算错误
   - 解决方案：修复当前回测期号的获取，确保它是数字字符串

4. **推荐买号统计卡片没有显示图表**：
   - 原因：需要查看 `drawBuyNumberChart` 函数的实现
   - 解决方案：修复图表绘制函数

## 修复步骤
1. 修复 `renderLatestDrawInfo` 函数，使用 `drawDate` 字段
2. 修复 `renderDetailDataSecondLast` 函数，从返回对象中提取期号
3. 修复 `renderDetailDataThirdLast` 函数，从返回对象中提取期号
