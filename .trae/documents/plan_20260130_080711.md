# 修改xia_qi_hou_qu_kai_jiang_yu_ce.html页面倒数2期卡片功能

## 目标
修改`xia_qi_hou_qu_kai_jiang_yu_ce.html`页面的"倒数2期两球组合后区平均率最高统计期详情"卡片，使其功能与`dao_shu_2_qi_hou_ping_jun_lv_zui_gao_detail.html`页面的对应卡片一致，并添加数据过滤功能。

## 实现步骤

### 1. 添加回测函数
- 在`js/xia_qi_hou_qu_kai_jiang_yu_ce.js`中添加`performSearchSecondLastBack`函数
- 实现多阶段搜索策略，从大到小变化步长
- 支持三种回测方法：出现最多、出现最少、出现平均
- 添加进度显示和终止回测功能
- 使用`huo_qu_dao_shu_2_qi_hou_mai_hao_hui_ce`接口获取回测数据

### 2. 实现数据渲染和过滤
- 添加`renderDetailDataSecondLastBack`函数
- 实现数据过滤逻辑：
  - 如果平均正确率相同，下下期后区推荐买号相同，则任意显示一条
  - 如果平均正确率相同，下下期后区推荐买号不同，则都要显示
- 渲染回测结果表格
- 添加复制到剪贴板功能

### 3. 实现后区推荐买号功能
- 确保使用正确的API接口获取后区推荐买号
- 参考`dao_shu_2_qi_hou_ping_jun_lv_zui_gao_detail.html`页面的实现
- 调用`dao_shu_2_qi_hou_qu_liang_qiu_zu_he`接口获取后区组合数据
- 统计每个号码的出现次数
- 根据回测方法计算推荐买号

### 4. 添加事件监听器
- 为"开始回测"按钮添加点击事件
- 为"终止回测"按钮添加点击事件
- 确保按钮状态正确切换

### 5. 确保UI一致性
- 确保进度条和状态显示与参考页面一致
- 确保表格结构和样式与参考页面一致
- 确保错误处理和提示信息与参考页面一致
