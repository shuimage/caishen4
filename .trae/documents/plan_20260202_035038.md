# 实现总回测控制功能

## 1. 添加总回测控制功能

### 1.1 添加开始全部回测功能
- 为 `startAllBacktestBtn` 添加点击事件监听器
- 实现 `startAllBacktest()` 函数，依次调用 `performSearch()`, `performSearch2()`, `performSearch3()`, `performSearch4()`, `performSearch5()` 函数
- 显示总进度条，更新总回测进度

### 1.2 添加终止全部回测功能
- 为 `stopAllBacktestBtn` 添加点击事件监听器
- 实现 `stopAllBacktest()` 函数，设置全局终止标志 `window.isStopped = true`

### 1.3 添加保存回测结果功能
- 为 `saveBacktestResultsBtn` 添加点击事件监听器
- 实现 `saveBacktestResults()` 函数，将当前回测期的回测数据存储到数据库中
- 在回测过程中禁用该按钮，回测完成后启用

### 1.4 添加加载回测结果功能
- 为 `loadBacktestResultsBtn` 添加点击事件监听器
- 实现 `loadBacktestResults()` 函数，从数据库中加载当前回测期的数据
- 如果有数据，则自动填充到各个卡片中

### 1.5 添加推荐杀号统计图表自动刷新功能
- 在每个 `performSearch()` 系列函数完成后，调用图表刷新函数
- 实现 `refreshBuyNumberChart()` 函数，重新获取数据并更新图表
