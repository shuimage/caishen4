## 修复保存回测结果功能

### 问题分析
在 `xia_qi_hou_qu_kai_jiang_bi_sha.html` 页面上，点击"保存回测结果"按钮时，只显示一个提示"保存回测结果功能待实现"，而没有实际保存数据到数据库。

### 解决方案
参考 `xia_qi_qian_qu_kai_jiang_bi_sha.html` 页面上的成功实现，实现相同的保存功能。

### 实现步骤
1. **实现 `saveBacktestResults` 函数**
   - 收集所有带有 `detail-list` 类的表格数据
   - 从每个表格中提取行数据，包括回测方法、回测期数、统计期数、平均正确率、当前期号、推荐号码等

   - 使用 fetch API 发送 POST 请求到 `http://localhost:18889/bao_cun_hui_ce_jie_guo` 保存到数据库
   - 处理成功和失败的情况，并给用户适当的提示

2. **修改保存按钮的点击事件**
   - 将原来的 alert 提示替换为调用 `saveBacktestResults` 函数

### 技术要点
- 使用 async/await 处理异步操作
- 使用 fetch API 进行网络请求
- 正确收集表格数据，包括从元素中提取文本和属性
- 处理成功和失败的情况，给用户明确的反馈
- 遵循与其他页面相同的实现模式，确保代码一致性
