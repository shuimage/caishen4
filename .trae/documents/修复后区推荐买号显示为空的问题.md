# 修复后区推荐买号显示为空的问题

## 问题分析
在 `xia_qi_hou_qu_kai_jiang_bi_sha.html` 页面中，当回测完成后，"最近期两球组合后区平均率最低统计期详情"和"倒数2期两球组合后区平均率最低统计期详情"卡片有时会显示空的后区推荐买号。

通过代码分析，我发现问题出在以下两个函数中：
1. `huo_qu_hou_qu_tui_jian_bi_sha_hao`（最近期后区推荐杀号）
2. `huo_qu_hou_qu_tui_jian_bi_sha_hao2`（倒数2期后区推荐杀号）

当使用"出现最少"方法时，如果所有号码的计数都为0，函数没有正确处理这种情况，可能导致返回空数组。

## 修复方案

### 1. 修改 `huo_qu_hou_qu_tui_jian_bi_sha_hao` 函数
- 在 `backtestMethod === 'least'` 分支中，添加检查如果所有计数都为0，返回1-12所有号码的逻辑
- 确保 API 调用失败时返回合理的默认值

### 2. 修改 `huo_qu_hou_qu_tui_jian_bi_sha_hao2` 函数
- 同样在 `backtestMethod === 'least'` 分支中，添加检查如果所有计数都为0，返回1-12所有号码的逻辑
- 确保 API 调用失败时返回合理的默认值

### 3. 验证修复
- 测试"最近期两球组合后区平均率最低统计期详情"卡片，确保"出现最少"方法在统计期数为1850期时能正确显示后区推荐杀号
- 测试"倒数2期两球组合后区平均率最低统计期详情"卡片，确保类似情况下能正确显示后区推荐买号

1. **文件：** `d:\中啦\caishen4\qian\js\xia_qi_hou_qu_kai_jiang_bi_sha.js`
