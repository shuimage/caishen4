# 修复网站崩溃问题并实现图标按钮替换

## 问题分析
网站崩溃的原因是浏览器请求了 `/@vite/client` 资源，这是 Vite 开发服务器的客户端脚本，但我们的项目使用的是简单的 Node.js HTTP 服务器，不支持 Vite。

## 修复步骤

### 1. 检查并修复所有 HTML 文件
- 遍历所有修改过的 HTML 文件，确保没有 Vite 相关的 script 标签
- 修复 HTML 文件中可能存在的结构问题
- 确保按钮修改没有破坏页面功能

### 2. 实现图标按钮替换
- 将所有复制按钮色块替换为带有复制图标的按钮
- 将所有回测按钮色块替换为带有回测图标的按钮
- 确保图标按钮具有良好的视觉效果和交互体验

### 3. 验证修复效果
- 重启前端服务器
- 清除浏览器缓存或使用无痕模式测试网站
- 确保所有页面都能正常访问
- 验证图标按钮功能正常

## 技术方案

### 图标按钮设计
- 使用 SVG 图标，确保在各种设备上都有良好的显示效果
- 图标按钮使用统一的样式，包括大小、颜色和圆角
- 为图标按钮添加悬停效果和点击反馈
