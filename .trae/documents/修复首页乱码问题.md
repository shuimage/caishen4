## 问题分析
1. **现象**：首页 http://localhost:8080/ 出现乱码，标题显示为"大乐透统计分�?- 首页"
2. **原因**：index.html 文件本身的编码出现问题，在保存时可能使用了错误的编码格式
3. **验证**：
   - 服务器返回的 Content-Type 头正确设置了 `text/html; charset=utf-8`
   - HTML 文件本身也正确设置了 `<meta charset="UTF-8">`
   - 其他 HTML 文件显示正常，只有 index.html 出现乱码

## 修复计划
1. **备份当前文件**：先备份当前的 index.html 文件，防止意外丢失
2. **创建新文件**：使用正确的 UTF-8 编码创建新的 index.html 文件
3. **修复乱码内容**：将原始内容复制到新文件中，修复出现乱码的地方
4. **验证修复效果**：测试修复后的页面是否正常显示

## 实施步骤
1. 使用 `cp index.html index.html.bak` 备份当前文件
2. 重新创建 index.html 文件，确保使用 UTF-8 编码
3. 复制原始内容，修复标题和其他可能出现乱码的地方
4. 重启服务器并测试页面显示效果
