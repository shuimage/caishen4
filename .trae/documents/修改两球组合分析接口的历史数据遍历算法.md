# 修改两球组合分析接口的历史数据遍历算法

## 问题描述
需要将 `倒数5期两球组合前区.js` 和 `倒数5期两球组合后区.js` 两个文件中的历史数据遍历算法从"查找组合出现位置并统计下下下期号码"改为"查找组合出现位置并统计下下下下下期号码"。

## 算法分析
### 当前算法逻辑
1. 历史数据按issue降序排列
2. 当前期（组合出现的期数）：`historyData[i]`
3. 下下下期（期号比当前期大3）：`historyData[i - 3]`
4. 遍历范围：`for (let i = 3; i < historyData.length; i++)`

### 修改后算法逻辑
1. 历史数据按issue降序排列
2. 当前期（组合出现的期数）：`historyData[i]`
3. 下下下下下期（期号比当前期大5）：`historyData[i - 5]`
4. 遍历范围：`for (let i = 5; i < historyData.length; i++)`

## 修改点

### 1. 倒数5期两球组合前区.js
- **第109行**：更新注释 `// 存储这个组合出现时下下期开出的号码` 为 `// 存储这个组合出现时下下下下下期开出的号码`
- **第117行**：修改循环条件 `for (let i = 3; i < historyData.length; i++)` 为 `for (let i = 5; i < historyData.length; i++)`
- **第119行**：修改变量名和索引 `const nextNextNextDraw = historyData[i - 3];` 为 `const nextNextNextNextNextDraw = historyData[i - 5];`
- **第121-122行**：修改条件判断 `if (!nextNextNextDraw) continue;` 为 `if (!nextNextNextNextNextDraw) continue;`
- **第149-159行**：将所有 `nextNextNextDraw` 改为 `nextNextNextNextNextDraw`
- **第168-176行**：将所有 `nextNextNext` 改为 `nextNextNextNextNext`

### 2. 倒数5期两球组合后区.js
- **第109行**：更新注释 `// 存储这个组合出现时下下期开出的号码` 为 `// 存储这个组合出现时下下下下下期开出的号码`
- **第117行**：修改循环条件 `for (let i = 3; i < historyData.length; i++)` 为 `for (let i = 5; i < historyData.length; i++)`
- **第119行**：修改变量名和索引 `const nextNextNextDraw = historyData[i - 3];` 为 `const nextNextNextNextNextDraw = historyData[i - 5];`
- **第121-122行**：修改条件判断 `if (!nextNextNextDraw) continue;` 为 `if (!nextNextNextNextNextDraw) continue;`
- **第149-159行**：将所有 `nextNextNextDraw` 改为 `nextNextNextNextNextDraw`
- **第168-176行**：将所有 `nextNextNext` 改为 `nextNextNextNextNext`

## 预期效果
修改后，两个接口将统计每个组合在历史数据中出现时下下下下下期（比当前期大5期）的号码分布，而不是原来的下下下期（比当前期大3期）。
