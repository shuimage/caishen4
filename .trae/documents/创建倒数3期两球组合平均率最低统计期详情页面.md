# 倒数3期两球组合平均率最低统计期详情页面

## 页面概述
创建一个新页面`dao_shu_3_qi_ping_jun_lv_zui_di_detail.html`，用于显示倒数3期两球组合平均率最低统计期的详细信息，包括回测结果、平均正确率和前区推荐买号。

## 核心功能
1. **倒数3期开奖信息展示** - 显示倒数3期的开奖信息
2. **平均率最低统计期搜索** - 搜索并显示平均正确率最低的统计期
3. **回测结果展示** - 显示不同统计期的回测结果和平均正确率
4. **下下下期前区推荐买号** - 根据搜索结果显示下下下期的前区推荐买号
5. **支持三种回测方法** - 出现最多、出现最少、出现平均

## 技术实现
1. **基于模板页面**：`sha_qiu_ping_jun_lv_zui_di_detail.html`
2. **回测算法**：与`dao_shu_3_qi_mai_hao_hui_ce_xiang_qing.html`中的平均正确率算法相同
3. **推荐买号算法**：与`dao_shu_3_qi_liang_qiu_zu_he.html`中的前区推荐买号算法相同
4. **接口调用**：
   - `http://localhost:18889/dao_shu_3_qi_mai_hao_hui_ce` - 获取回测数据
   - `http://localhost:18889/sql_dao_shu_3_qi` - 获取倒数3期开奖信息
   - `http://localhost:18889/dao_shu_3_qi_liang_qiu_zu_he` - 获取前区推荐买号数据

## 页面结构
1. **页面标题**：倒数3期两球组合平均率最低统计期详情
2. **倒数3期开奖信息区域**：显示倒数3期的开奖信息
3. **回测结果列表区域**：显示不同统计期的回测结果
4. **进度显示区域**：显示搜索进度
5. **操作按钮**：开始回测、终止回测、返回

## 关键修改点
1. 修改页面标题和描述为"倒数3期两球组合平均率最低统计期详情"
2. 使用`dao_shu_3_qi_mai_hao_hui_ce`接口获取回测数据
3. 使用`sql_dao_shu_3_qi`接口获取倒数3期开奖信息
4. 使用`dao_shu_3_qi_liang_qiu_zu_he`接口获取前区推荐买号数据
5. 期号计算修改为最新期号+3，显示"下下下期"
6. 前区推荐买号算法与`dao_shu_3_qi_liang_qiu_zu_he.html`保持一致
7. 支持浏览器标签不可见时正常运行回测
