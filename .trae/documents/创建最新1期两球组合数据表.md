# 创建最新1期两球组合数据表

## 1. 需求分析

用户需要在数据库中创建一个表，用于存储最新1期两球组合的数据，包含以下字段：
- 前区组合球1
- 前区组合球2
- 组合球出现时的期号
- 组合球出现期号的前区开奖号码
- 组合球出现时期号的下一期期号
- 组合球出现时下一期期号的前区开奖号码

## 2. 数据库配置

从数据库配置文件中了解到：
- 数据库类型：MySQL
- 数据库名称：letou
- 数据库用户：root
- 数据库密码：123456
- 数据库主机：127.0.0.1
- 数据库端口：3306

## 3. 表结构设计

| 字段名 | 数据类型 | 描述 | 约束 |
|--------|----------|------|------|
| id | INT | 主键，自增 | PRIMARY KEY, AUTO_INCREMENT |
| front_ball_1 | INT | 前区组合球1 | NOT NULL, CHECK (front_ball_1 BETWEEN 1 AND 35) |
| front_ball_2 | INT | 前区组合球2 | NOT NULL, CHECK (front_ball_2 BETWEEN 1 AND 35) |
| combination_period | VARCHAR(10) | 组合球出现时的期号 | NOT NULL |
| combination_front_numbers | VARCHAR(50) | 组合球出现期号的前区开奖号码 | NOT NULL |
| next_period | VARCHAR(10) | 组合球出现时期号的下一期期号 | NOT NULL |
| next_front_numbers | VARCHAR(50) | 组合球出现时下一期期号的前区开奖号码 | NOT NULL |
| created_at | DATETIME | 记录创建时间 | DEFAULT CURRENT_TIMESTAMP |
| updated_at | DATETIME | 记录更新时间 | DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP |

## 4. 索引设计

为了提高查询效率，添加以下索引：
- 组合球索引：(front_ball_1, front_ball_2) - 用于快速查询特定组合球的数据
- 期号索引：(combination_period) - 用于快速查询特定期号的数据

## 5. 实现步骤

1. 创建一个名为`create_two_ball_combination_table.js`的JavaScript文件
2. 使用数据库配置文件中的连接池连接数据库
3. 编写SQL语句创建表
4. 执行SQL语句
5. 关闭数据库连接

## 6. SQL语句

```sql
CREATE TABLE IF NOT EXISTS latest_two_ball_combinations (
  id INT AUTO_INCREMENT PRIMARY KEY,
  front_ball_1 INT NOT NULL CHECK (front_ball_1 BETWEEN 1 AND 35),
  front_ball_2 INT NOT NULL CHECK (front_ball_2 BETWEEN 1 AND 35),
  combination_period VARCHAR(10) NOT NULL,
  combination_front_numbers VARCHAR(50) NOT NULL,
  next_period VARCHAR(10) NOT NULL,
  next_front_numbers VARCHAR(50) NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_combination (front_ball_1, front_ball_2),
  INDEX idx_period (combination_period)
);
```

## 7. JavaScript脚本

```javascript
// create_two_ball_combination_table.js
const { query, pool } = require('./数据库配置.js');

async function createTable() {
  try {
    const sql = `
      CREATE TABLE IF NOT EXISTS latest_two_ball_combinations (
        id INT AUTO_INCREMENT PRIMARY KEY,
        front_ball_1 INT NOT NULL CHECK (front_ball_1 BETWEEN 1 AND 35),
        front_ball_2 INT NOT NULL CHECK (front_ball_2 BETWEEN 1 AND 35),
        combination_period VARCHAR(10) NOT NULL,
        combination_front_numbers VARCHAR(50) NOT NULL,
        next_period VARCHAR(10) NOT NULL,
        next_front_numbers VARCHAR(50) NOT NULL,
        created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
        updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
        INDEX idx_combination (front_ball_1, front_ball_2),
        INDEX idx_period (combination_period)
      );
    `;
    
    await query(sql);
    console.log('最新1期两球组合数据表创建成功');
  } catch (error) {
    console.error('创建表失败:', error.message);
  } finally {
    // 关闭连接池
    await pool.end();
  }
}

createTable();
```

