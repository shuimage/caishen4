# 回滚版本到V1.1.0计划

## 1. 检查分支状态
- 查看所有本地分支，确认V1.1.0分支是否存在
- 检查远程仓库配置，确认可以从GitHub获取代码

## 2. 回滚操作
- 切换到V1.1.0分支
- 拉取最新的V1.1.0代码
- 清理工作目录，删除未跟踪的文件和文件夹

## 3. 验证回滚结果
- 检查当前分支是否为V1.1.0
- 验证代码是否为V1.1.0版本
- 测试网站是否能正常运行

## 4. 后续处理
- 启动前端和后端服务器
- 验证页面是否能正常访问
- 确认接口调用正常

## 注意事项
- 由于V1.1.1分支存在大量乱码文件，我们将直接切换到V1.1.0分支，不保留当前修改
- 清理工作目录时会删除所有未跟踪的文件，请确保没有重要文件未提交
