# 实现三球组合前区杀号回测功能

## 需求分析
- 在 `san_qiu_fen_xi.html` 页面的"前区推荐杀号"区域添加"查看回测结果"链接
- 创建新页面 `san_qiu_sha_hao_hui_ce_xiang_qing.html` 显示回测结果
- 实现回测统计范围内的推荐杀号与真实开奖结果对比
- 使用与 `san_qiu_fen_xi.html` 相同的前区推荐杀号算法

## 实现方案

### 1. 前端实现

#### 1.1 修改 `san_qiu_fen_xi.html`
- 在"前区推荐杀号"区域添加"查看回测结果"链接
- 链接指向新创建的回测结果页面

#### 1.2 创建回测结果页面 `san_qiu_sha_hao_hui_ce_xiang_qing.html`
- 页面结构参考 `sha_hao_hui_ce_xiang_qing.html`
- 实现 API 调用功能，获取三球组合前区杀号回测数据
- 渲染回测结果列表，包含以下字段：
  - 当前回测期号
  - 前区推荐杀号
  - 下期开奖期号
  - 下期实际开奖前区
  - 正确杀号数量
  - 错误杀号数量
- 实现期数选择功能，支持不同统计范围

### 2. 后端实现

#### 2.1 创建新的 API 路由
- 在 `server.js` 中注册新的路由 `san_qiu_sha_hao_hui_ce`

#### 2.2 实现回测逻辑
- 创建 `san_qiu_sha_hao_hui_ce.js` 文件
- 实现与 `san_qiu_fen_xi` 相同的前区推荐杀号算法
- 实现回测功能，对比推荐杀号与实际开奖结果
- 返回回测数据，包含正确杀号和错误杀号数量

## 技术要点

### 1. 杀号算法
- 确保回测功能使用与 `san_qiu_fen_xi.html` 相同的前区推荐杀号算法
- 算法基于三球组合的统计规律，找出在所有组合中出现次数为 0 的号码

### 2. 回测逻辑
- 遍历统计范围内的每一期数据
- 对每一期，使用历史数据计算推荐杀号
- 比较推荐杀号与下一期实际开奖号码
- 计算正确杀号和错误杀号数量

### 3. 数据交互
- 前端使用 fetch API 调用后端接口
- 后端返回 JSON 格式的回测数据
- 前端动态渲染回测结果列表

## 预期效果

1. 在 `san_qiu_fen_xi.html` 页面的"前区推荐杀号"区域可以看到"查看回测结果"链接
2. 点击链接后跳转到 `san_qiu_sha_hao_hui_ce_xiang_qing.html` 页面
3. 回测结果页面显示最新1期三球组合前区杀号回测结果
4. 支持选择不同的统计范围，重新获取回测数据
5. 回测结果列表清晰展示当前回测期号、推荐杀号、下期开奖信息和杀号结果
