# 实现倒数2期三球组合前区杀号回测功能

## 需求分析
- 在 `dao_shu_2_qi_san_qiu_zu_he.html` 页面的“前区推荐杀号”区域添加"查看回测结果"链接
- 创建新页面 `dao_shu_2_qi_san_qiu_sha_hao_hui_ce_xiang_qing.html` 显示回测结果
- 实现回测统计范围内的推荐杀号与真实开奖结果对比
- 使用与 `dao_shu_2_qi_san_qiu_zu_he.html` 相同的前区推荐杀号算法
- 回测结果列表包含：当前回测期号、前区推荐杀号、下期开奖期号、下期实际开奖前区、正确杀号数量、错误杀号数量

## 实现方案

### 1. 后端实现

#### 1.1 创建新的 API 文件 `dao_shu_2_qi_san_qiu_sha_hao_hui_ce.js`
- 实现与 `倒数2期三球组合.js` 相同的前区推荐杀号算法
- 实现回测功能，对比推荐杀号与实际开奖结果
- 返回回测数据，包含正确杀号和错误杀号数量

#### 1.2 在 `server.js` 中注册新路由
- 导入新的API模块
- 注册路由 `dao_shu_2_qi_san_qiu_sha_hao_hui_ce`

### 2. 前端实现

#### 2.1 修改 `dao_shu_2_qi_san_qiu_zu_he.html`
- 在"前区推荐杀号"区域添加"查看回测结果"链接
- 链接指向新创建的回测结果页面

#### 2.2 创建回测结果页面 `dao_shu_2_qi_san_qiu_sha_hao_hui_ce_xiang_qing.html`
- 页面结构参考 `san_qiu_sha_hao_hui_ce_xiang_qing.html`
- 实现 API 调用功能，获取倒数2期三球组合前区杀号回测数据
- 渲染回测结果列表，包含所需字段
- 实现期数选择功能，支持不同统计范围

## 技术要点

### 1. 杀号算法
- 与 `dao_shu_2_qi_san_qiu_zu_he.html` 相同的算法：检查号码在所有三球组合的统计中是否均未出现

### 2. 回测逻辑
- 遍历统计范围内的每一期数据
- 对每一期，使用历史数据计算推荐杀号
- 比较推荐杀号与下一期实际开奖号码
- 计算正确杀号和错误杀号数量

### 3. 数据交互
- 前端使用 fetch API 调用后端接口
- 后端返回 JSON 格式的回测数据
- 前端动态渲染回测结果列表
