# 实现回测结果数据库缓存功能

## 1. 核心设计思路
- **缓存键设计**：使用唯一标识符标识回测结果，包含回测类型、当前期号、回测期数等关键信息
- **缓存检查机制**：在每个回测函数开始时检查数据库中是否已有相同条件的回测结果
- **结果保存机制**：回测完成后将结果保存到数据库，以便后续快速获取
- **API交互**：设计两个新API用于保存和获取回测结果

## 2. API设计
- **保存回测结果**：`POST /bao_cun_hui_ce_jie_guo`
  - 参数：`cache_key`（缓存唯一键）、`backtest_results`（回测结果数据）、`current_period`（当前期号）
  - 返回：成功/失败状态

- **获取回测结果**：`GET /huo_qu_hui_ce_jie_guo?cache_key=xxx`
  - 参数：`cache_key`（缓存唯一键）
  - 返回：缓存的回测结果或空

## 3. 前端实现步骤

### 3.1 添加API调用函数
```javascript
// 保存回测结果到数据库
async function bao_cun_hui_ce_jie_guo(cacheKey, backtestResults, currentPeriod) {
  try {
    const response = await fetch('http://localhost:18889/bao_cun_hui_ce_jie_guo', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        cache_key: cacheKey,
        backtest_results: backtestResults,
        current_period: currentPeriod
      })
    });
    const result = await response.json();
    return result.success;
  } catch (error) {
    console.error('保存回测结果失败:', error);
    return false;
  }
}

// 从数据库获取回测结果
async function huo_qu_hui_ce_jie_guo(cacheKey) {
  try {
    const response = await fetch(`http://localhost:18889/huo_qu_hui_ce_jie_guo?cache_key=${cacheKey}`);
    const result = await response.json();
    return result.success ? result.data : null;
  } catch (error) {
    console.error('获取回测结果失败:', error);
    return null;
  }
}
```

## 4. 数据库设计建议
- **表名**：`backtest_cache`
- **字段**：
  - `cache_key`：VARCHAR(255)，主键
  - `backtest_results`：TEXT，存储回测结果JSON
  - `current_period`：VARCHAR(20)，当前期号
  - `created_at`：DATETIME，创建时间
  - `updated_at`：DATETIME，更新时间
