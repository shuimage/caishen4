# 实现总回测控制功能

## 任务目标
在 `xia_qi_qian_qu_kai_jiang_bi_sha.html` 页面中实现以下功能：

1. **总回测控制**：点击"总回测控制"卡片的"开始回测"按钮，依次启动下方所有卡片的"开始回测"功能
2. **保存回测结果**：回测过程中"保存回测结果"按钮不可点击，回测完成后可以点击保存数据到数据库
3. **加载回测结果**：点击"加载回测结果"按钮，从数据库中加载当前回测期的数据
4. **自动刷新图表**：每回测完成一个卡片，自动刷新"推荐杀号统计"卡片中的图表

## 实现步骤

### 1. 添加总回测控制相关函数
在 JavaScript 代码末尾添加以下函数：

- **refreshBuyNumberChart()**：刷新推荐杀号统计图表
- **startAllBacktest()**：依次启动所有回测
- **saveBacktestResults()**：保存回测结果到数据库
- **loadBacktestResults()**：从数据库加载回测结果

### 2. 更新DOMContentLoaded事件监听器
在 `DOMContentLoaded` 事件监听器中添加总回测控制按钮的事件监听：

- 为 `startAllBacktestBtn` 添加点击事件监听，调用 `startAllBacktest()`
- 为 `saveBacktestResultsBtn` 添加点击事件监听，调用 `saveBacktestResults()`
- 为 `loadBacktestResultsBtn` 添加点击事件监听，调用 `loadBacktestResults()`

## 技术实现要点

- 使用 `async/await` 处理异步操作，确保回测按顺序执行
- 在回测过程中使用 `disabled` 属性控制保存按钮的可点击状态
- 使用 `try/catch/finally` 确保无论回测成功与否，按钮状态都能正确恢复
- 在每完成一个回测后调用 `refreshBuyNumberChart()` 刷新图表
- 实现基本的数据库操作函数框架，后续可根据实际数据库结构完善
