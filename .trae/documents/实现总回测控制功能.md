# 实现总回测控制功能

## 功能需求
点击“总回测控制”卡片中的“开始回测”按钮，依次执行下方的开始回测按钮，执行完一个再执行下一个。

## 实现步骤

### 1. 添加总回测执行函数
在 `js/xia_qi_hou_qu_kai_jiang_yu_ce.js` 文件中添加 `performAllBacktests` 函数，该函数将：
- 显示总回测进度条
- 依次调用各个回测函数：
  1. 最新一期：`performSearchNewestBack()`
  2. 倒数2期：`performSearchSecondLastBack()`
  3. 倒数3期：`performSearchThirdLastBack()`
  4. 倒数4期：`performSearchFourthLastBack()`
  5. 倒数5期：`performSearchFifthLastBack()`
  6. 近两期：`performSearchNearTwoPeriodsBack()`
- 实时更新总回测进度
- 处理回测终止的情况
- 回测完成后恢复按钮状态

### 2. 添加总回测终止函数
添加 `stopAllBacktests` 函数，用于终止所有正在执行的回测。

### 3. 添加事件监听器
为“总回测控制”卡片中的“开始回测”按钮和“终止回测”按钮添加事件监听器：
- `startAllBacktestBtn` 点击时调用 `performAllBacktests` 函数
- `stopAllBacktestBtn` 点击时调用 `stopAllBacktests` 函数

### 4. 更新总回测进度显示
在总回测过程中，实时更新总进度条和进度文本，显示当前正在执行的回测任务。

## 技术实现要点

### 1. 串行执行回测
使用 `async/await` 确保回测函数按顺序执行，执行完一个再执行下一个。

### 2. 进度计算
根据回测任务的总数和当前执行的任务索引，计算总回测进度。

### 3. 终止控制
添加 `isStopped` 标志，在每个回测函数执行前检查是否需要终止回测。

### 4. 按钮状态管理
在回测开始时，隐藏“开始回测”按钮，显示“终止回测”按钮；回测完成或终止后，恢复按钮状态。

## 预期效果

当用户点击“总回测控制”卡片中的“开始回测”按钮时：
1. 显示总回测进度条
2. 依次执行下方的每个回测卡片的回测任务
3. 每个回测任务执行完成后，自动开始下一个回测任务
4. 总进度条实时更新，显示当前回测进度
5. 用户可以点击“终止回测”按钮停止所有回测任务
6. 所有回测任务执行完成后，总进度条显示完成状态，按钮恢复初始状态
