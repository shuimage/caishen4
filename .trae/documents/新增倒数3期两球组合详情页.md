# 新增倒数3期两球组合详情页实现计划

## 1. 前端实现

### 1.1 创建详情页文件
- 创建 `dao_shu_3_qi_liang_qiu_zu_he_xiang_qing.html` 文件，参考现有组合详情页结构
- 页面标题："大乐透统计分析 - 倒数3期两球组合详情"
- 导航栏：保持与其他组合详情页一致，当前页高亮

### 1.2 页面结构设计
- **最新开奖信息**：显示最新一期开奖数据
- **倒数3期开奖信息**：显示倒数第3期开奖数据
- **组合信息**：显示组合号码、统计范围、出现次数等
- **记录表格**：显示组合出现的期号、开奖号、下下下期期号、下下下期开奖号
- **分页控件**：支持上一页/下一页导航，每页显示15条记录

### 1.3 JavaScript逻辑
- **页面初始化**：加载完成后调用 `renderAllData()` 函数
- **URL参数解析**：解析 `combination`、`type`、`stats_range` 参数
- **数据获取**：
  - 调用 `sql_dao_shu_3_qi` 接口获取倒数3期开奖信息
  - 调用新增的 `dao_shu_3_qi_liang_qiu_zu_he_xiang_qing` 接口获取组合详情数据
- **数据渲染**：
  - 渲染最新和倒数3期开奖信息
  - 渲染组合详情表格，高亮显示组合球和目标球
  - 实现分页功能
- **特殊处理**：
  - 数据为空时显示友好提示
  - 接口失败时弹出提示，不使用模拟数据
  - 支持主题切换

## 2. 后端实现

### 2.1 创建接口文件
- 创建 `倒数3期两球组合详情.js` 文件，参考现有 `倒数2期两球组合详情服务器.js` 实现
- 接口路径：`/dao_shu_3_qi_liang_qiu_zu_he_xiang_qing`
- 请求方法：`POST`

### 2.2 接口逻辑
- **请求参数**：
  ```json
  {
    "latest_period": "25133",
    "type": "front",
    "combinations": ["02-10"],
    "stats_range": 1000,
    "target_ball": 9
  }
  ```
- **数据库查询**：
  - 查询指定统计范围内的开奖数据
  - 筛选包含该组合的开奖记录
  - 对于每条匹配记录，获取其下下下期的开奖数据（通过 `bian_hao` 字段计算）
- **数据处理**：
  - 格式化日期和号码
  - 统计组合出现次数
  - 构建返回数据结构
- **响应格式**：
  ```json
  {
    "code": 200,
    "data": [
      {
        "index": 1,
        "period": "25120",
        "draw_info": [2, 10, 15, 20, 25],
        "next_next_next_period": "25123",
        "next_next_next_draw_info": [5, 9, 12, 18, 22]
      }
    ]
  }
  ```

## 6. 技术要点

- **下下下期计算**：通过 `bian_hao` 字段计算，当前期 `bian_hao` + 3 即为下下下期
- **组合号码处理**：将三球组合拆分为两球组合和目标球
- **高亮显示**：组合球使用特殊样式，目标球使用紫色样式
- **分页实现**：前端分页，每页显示15条记录
- **错误处理**：接口失败时弹出提示，不使用模拟数据
