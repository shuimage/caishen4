# 添加回测期数和统计期数下拉选项并实现动态更新

## 需求分析
用户要求在倒数3期三球组合前区杀号回测结果页面的红框和蓝框处分别增加“回测期数”和统计期数的下拉选项，改变这两个值后，列表数据和前区推荐杀号算法的统计期数跟着改变。

## 实现步骤

### 1. 修改 `dao_shu_3_qi_san_qiu_sha_hao_hui_ce_xiang_qing.html` 页面
- 在页面顶部添加两个下拉选项，分别对应回测期数和统计期数
- 调整页面布局，确保下拉选项显示在红框和蓝框位置
- 为下拉选项添加事件监听器，当值改变时重新获取数据

### 2. 修改 JavaScript 代码
- 添加回测期数和统计期数的状态管理
- 修改 `huo_qu_dao_shu_3_qi_san_qiu_sha_hao_hui_ce` 函数，支持接收回测期数和统计期数参数
- 修改 `fetchAndRenderBacktestData` 函数，传递回测期数和统计期数参数
- 为下拉选项添加 `onchange` 事件，触发数据重新加载

### 3. 修改后端接口 `dao_shu_3_qi_san_qiu_sha_hao_hui_ce.js`
- 修改 `getDaoShu3QiSanQiuShaHaoHuiCe` 函数，支持接收回测期数和统计期数参数
- 根据回测期数限制回测结果的数量
- 根据统计期数调整推荐杀号算法的统计范围

### 4. 测试验证
- 确保下拉选项正常显示
- 确保改变下拉选项后，数据重新加载
- 确保回测期数和统计期数正确传递给后端
- 确保推荐杀号算法的统计期数跟着改变

## 技术要点
- 使用 URL 查询参数传递回测期数和统计期数
- 保持前后端参数命名一致
- 实现下拉选项的联动更新
- 确保页面布局美观，符合用户预期
