# 集成近两期两球组合平均率最高统计期详情功能

## 目标
在 `xia_qi_kai_jiang_yu_ce.html` 页面的 "近两期两球组合平均率最高统计期详情" 卡片中集成 `jin_liang_qi_ping_jun_lv_zui_gao_detail.html` 的功能，并添加过滤逻辑。

## 实现步骤

### 1. 添加辅助函数
- **`huo_qu_jin_liang_qi_mai_hao_hui_ce`**：从后端获取近两期回测数据
- **`testStatsPeriodNearTwoPeriods`**：测试单个统计期值的平均正确率
- **`huo_qu_qian_qu_tui_jian_mai_hao_near_two_periods`**：获取前区推荐买号

### 2. 实现回测函数
- **`performSearchNearTwoPeriods`**：执行回测，使用多阶段搜索策略
  - 多阶段搜索策略（步长从 100 到 5）
  - 支持三种回测方法（出现最多、出现最少、出现平均）
  - 实时进度显示
  - 错误处理和终止功能

### 3. 实现渲染函数
- **`renderDetailDataNearTwoPeriods`**：渲染回测结果
  - 添加过滤逻辑：如果回测方法相同，平均正确率相同，下一期前区推荐买号相同，则任意显示一条；否则均显示
  - 生成推荐买号合集
  - 支持复制功能

### 4. 更新控制函数
- **`setupBacktestControls`**：确保近两期模块的回测按钮能正确调用 `performSearchNearTwoPeriods` 函数

### 5. 验证功能
- 确保所有 API 调用正确
- 验证过滤逻辑是否按要求工作
- 确保进度显示和错误处理正常
- 验证复制功能是否可用

## 技术要点
- 使用与其他卡片相同的代码模式和命名约定
- 确保错误处理和进度显示与其他卡片一致
- 实现正确的过滤逻辑，基于回测方法、平均正确率和下一期前区推荐买号
- 计算正确的下一期期号（最近期的期号 + 1）
- 确保与后端 API 的正确集成

## 预期结果
"近两期两球组合平均率最高统计期详情" 卡片将具有与 `jin_liang_qi_ping_jun_lv_zui_gao_detail.html` 相同的功能，同时添加了按要求的过滤逻辑，只显示符合条件的回测结果。
