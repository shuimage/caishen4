# 快速开始

本文档介绍如何快速搭建和运行彩神4项目。

## 环境要求

### 必需软件

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| Node.js | >= 16.x | JavaScript 运行时 |
| MySQL | >= 5.7 | 数据库服务器 |
| npm | >= 8.x | Node.js 包管理器 |

### 验证环境

```bash
# 检查 Node.js 版本
node -v

# 检查 npm 版本
npm -v

# 检查 MySQL 服务
mysql -V
```

## 安装步骤


### 3. 配置数据库

#### 3.1 创建数据库

```sql
CREATE DATABASE letou CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 3.2 创建数据表

执行以下 SQL 创建主表：

```sql
-- 开奖结果主表
CREATE TABLE lottery_results (
    id INT AUTO_INCREMENT PRIMARY KEY,
    issue VARCHAR(50) NOT NULL,
    draw_date DATE,
    week VARCHAR(10),
    red TEXT,
    blue TEXT,
    sum INT,
    span INT,
    area_ratio VARCHAR(20),
    odd_even_ratio VARCHAR(20),
    bian_hao VARCHAR(50),
    UNIQUE KEY unique_issue (issue)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 备用表 letou
CREATE TABLE letou (
    id INT AUTO_INCREMENT PRIMARY KEY,
    riqi DATE,
    qihao VARCHAR(50),
    qian1 INT,
    qian2 INT,
    qian3 INT,
    qian4 INT,
    qian5 INT,
    hou1 INT,
    hou2 INT,
    bian_hao VARCHAR(50)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 回测结果缓存表
CREATE TABLE backtest_results (
    id INT AUTO_INCREMENT PRIMARY KEY,
    cache_key VARCHAR(255) NOT NULL UNIQUE,
    backtest_results JSON NOT NULL,
    current_period VARCHAR(50),
    backtest_period VARCHAR(50),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 前区深度预测表
CREATE TABLE qian_qu_shen_du_yu_ce (
    id INT AUTO_INCREMENT PRIMARY KEY,
    period INT NOT NULL,
    backtest_period INT NOT NULL,
    card_index INT NOT NULL,
    card_name VARCHAR(255) NOT NULL,
    buy_numbers JSON NOT NULL,
    accuracy_data JSON NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY unique_period_backtest_card (period, backtest_period, card_index)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 后区深度预测表
CREATE TABLE hou_qu_shen_du_yu_ce (
    id INT AUTO_INCREMENT PRIMARY KEY,
    period INT NOT NULL,
    backtest_period INT NOT NULL,
    card_index INT NOT NULL,
    card_name VARCHAR(255) NOT NULL,
    buy_numbers JSON NOT NULL,
    accuracy_data JSON NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY unique_period_backtest_card (period, backtest_period, card_index)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 4. 配置环境变量

在 `hou/` 目录下创建 `.env` 文件：

```bash
cd d:\中啦\caishen4\hou
copy .env.example .env
```

编辑 `.env` 文件：

```env
# 数据库配置
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=123456
DB_NAME=letou
DB_PORT=3306
DB_POOL_LIMIT=10

# 服务器配置
PORT=8080
```

**配置说明：**

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| DB_HOST | localhost | 数据库主机地址 |
| DB_USER | root | 数据库用户名 |
| DB_PASSWORD | 123456 | 数据库密码 |
| DB_NAME | letou | 数据库名称 |
| DB_PORT | 3306 | 数据库端口 |
| DB_POOL_LIMIT | 10 | 连接池大小 |

## 常见问题

### 1. 数据库连接失败

**问题现象：** 启动时提示数据库连接错误

**解决方案：**
- 检查 MySQL 服务是否已启动
- 检查 `.env` 中的数据库配置是否正确
- 确认数据库 `letou` 已创建

### 2. 端口被占用

**问题现象：** `Error: listen EADDRINUSE: address already in use :::18889`

**解决方案：**
```bash
# 查找占用端口的进程
netstat -ano | findstr :18889

# 结束进程（以管理员身份运行）
taskkill /PID <进程ID> /F
```

### 3. 前端页面无法加载

**问题现象：** 访问 http://localhost:8080 显示 404

**解决方案：**
- 确认 `qian/` 目录存在且包含 `index.html`
- 检查前端服务器是否已启动
- 查看前端服务器控制台输出

## 生产环境部署

### 使用 PM2 进程管理

```bash
# 安装 PM2
npm install -g pm2

# 启动后端
pm2 start hou/server.js --name caishen4-backend

# 启动前端
pm2 start frontend-server.js --name caishen4-frontend

# 保存配置
pm2 save
pm2 startup
```

### Nginx 反向代理配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:18889/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
