# 数据库设计

本文档详细介绍彩神4项目的数据库设计。

## 数据库概览

- **数据库名**: `letou`
- **字符集**: `utf8mb4`
- **排序规则**: `utf8mb4_unicode_ci`
- **端口**: 3306

## 数据表清单

| 表名 | 说明 | 数据量 |
|------|------|--------|
| lottery_results | 开奖结果主表 | 数千条 |
| letou | 备用数据表 | 数千条 |
| backtest_results | 回测结果缓存表 | 动态增长 |
| qian_qu_shen_du_yu_ce | 前区深度预测结果表 | 动态增长 |
| hou_qu_shen_du_yu_ce | 后区深度预测结果表 | 动态增长 |

## 1. lottery_results（开奖结果主表）

存储大乐透历史开奖数据，是系统的核心数据表。

### 表结构

```sql
CREATE TABLE lottery_results (
    id INT AUTO_INCREMENT PRIMARY KEY COMMENT '自增ID',
    issue VARCHAR(50) NOT NULL COMMENT '期号，如 25121',
    draw_date DATE COMMENT '开奖日期',
    week VARCHAR(10) COMMENT '星期几 (1-7)',
    red TEXT COMMENT '前区红球号码，格式如 [1, 5, 12, 23, 30]',
    blue TEXT COMMENT '后区蓝球号码，格式如 [2, 7]',
    sum INT COMMENT '前区和值',
    span INT COMMENT '前区跨度(最大-最小)',
    area_ratio VARCHAR(20) COMMENT '区间比，如 1:2:2',
    odd_even_ratio VARCHAR(20) COMMENT '奇偶比，如 3:2',
    bian_hao VARCHAR(50) COMMENT '编号，如 LT00001',
    UNIQUE KEY unique_issue (issue)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 字段说明

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | INT | 是 | 主键，自增 |
| issue | VARCHAR(50) | 是 | 期号，唯一索引 |
| draw_date | DATE | 否 | 开奖日期 |
| week | VARCHAR(10) | 否 | 星期几，1=周一，7=周日 |
| red | TEXT | 否 | 前区5个红球，JSON数组格式 |
| blue | TEXT | 否 | 后区2个蓝球，JSON数组格式 |
| sum | INT | 否 | 前区号码之和 |
| span | INT | 否 | 前区最大号-最小号 |
| area_ratio | VARCHAR(20) | 否 | 三区分布比(1-12:13-24:25-35) |
| odd_even_ratio | VARCHAR(20) | 否 | 奇偶号码数量比 |
| bian_hao | VARCHAR(50) | 否 | 自定义编号 |

### 示例数据

| id | issue | draw_date | week | red | blue | sum | span | area_ratio | odd_even_ratio |
|----|-------|-----------|------|-----|------|-----|------|------------|----------------|
| 1 | 25121 | 2025-10-22 | 3 | [1, 5, 12, 23, 30] | [2, 7] | 71 | 29 | 1:2:2 | 3:2 |
| 2 | 25120 | 2025-10-20 | 1 | [3, 8, 15, 24, 33] | [5, 11] | 83 | 30 | 1:2:2 | 3:2 |

### 常用查询

```sql
-- 获取最新一期数据
SELECT * FROM lottery_results ORDER BY draw_date DESC LIMIT 1;

-- 获取倒数第2期数据
SELECT * FROM lottery_results ORDER BY draw_date DESC LIMIT 1, 1;

-- 获取最近100期数据
SELECT * FROM lottery_results ORDER BY draw_date DESC LIMIT 100;

-- 按期号范围查询
SELECT * FROM lottery_results WHERE issue >= '25100' AND issue <= '25121';
```

## 2. letou（备用数据表）

与 lottery_results 表数据同步，采用不同的字段结构存储。

### 表结构

```sql
CREATE TABLE letou (
    id INT AUTO_INCREMENT PRIMARY KEY COMMENT '自增ID',
    riqi DATE COMMENT '日期',
    qihao VARCHAR(50) COMMENT '期号',
    qian1 INT COMMENT '前区号码1',
    qian2 INT COMMENT '前区号码2',
    qian3 INT COMMENT '前区号码3',
    qian4 INT COMMENT '前区号码4',
    qian5 INT COMMENT '前区号码5',
    hou1 INT COMMENT '后区号码1',
    hou2 INT COMMENT '后区号码2',
    bian_hao VARCHAR(50) COMMENT '编号'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT | 主键 |
| riqi | DATE | 开奖日期 |
| qihao | VARCHAR(50) | 期号 |
| qian1-qian5 | INT | 前区5个号码 |
| hou1-hou2 | INT | 后区2个号码 |
| bian_hao | VARCHAR(50) | 自定义编号 |

## 3. backtest_results（回测结果缓存表）

缓存回测计算结果，避免重复计算。

### 表结构

```sql
CREATE TABLE backtest_results (
    id INT AUTO_INCREMENT PRIMARY KEY COMMENT '自增ID',
    cache_key VARCHAR(255) NOT NULL UNIQUE COMMENT '缓存键',
    backtest_results JSON NOT NULL COMMENT '回测结果JSON数据',
    current_period VARCHAR(50) COMMENT '当前期号',
    backtest_period VARCHAR(50) COMMENT '回测期数',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT | 主键 |
| cache_key | VARCHAR(255) | 缓存键，唯一索引 |
| backtest_results | JSON | 回测结果数据 |
| current_period | VARCHAR(50) | 当前分析的期号 |
| backtest_period | VARCHAR(50) | 回测统计期数 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 缓存键格式

```
backtest_{type}_{method}_{period}_{targetPeriod}

示例：
- backtest_front_most_100_25121
- backtest_back_least_200_25120
```

## 4. qian_qu_shen_du_yu_ce（前区深度预测表）

存储前区深度预测的计算结果。

### 表结构

```sql
CREATE TABLE qian_qu_shen_du_yu_ce (
    id INT AUTO_INCREMENT PRIMARY KEY COMMENT '自增ID',
    period INT NOT NULL COMMENT '预测期号',
    backtest_period INT NOT NULL COMMENT '回测期数',
    card_index INT NOT NULL COMMENT '卡片索引',
    card_name VARCHAR(255) NOT NULL COMMENT '卡片名称',
    buy_numbers JSON NOT NULL COMMENT '推荐买号集合',
    accuracy_data JSON NOT NULL COMMENT '准确率数据',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    UNIQUE KEY unique_period_backtest_card (period, backtest_period, card_index)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT | 主键 |
| period | INT | 预测目标期号 |
| backtest_period | INT | 用于回测的期数 |
| card_index | INT | 卡片索引号 |
| card_name | VARCHAR(255) | 卡片名称 |
| buy_numbers | JSON | 推荐购买的号码集合 |
| accuracy_data | JSON | 准确率统计数据 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

### 唯一索引

```sql
UNIQUE KEY unique_period_backtest_card (period, backtest_period, card_index)
```

确保同一期号、同一回测期数、同一卡片的记录唯一。

## 数据库连接配置

### 配置文件

文件路径: `hou/数据库配置.js`

```javascript
const dbConfig = {
  host: process.env.DB_HOST || '127.0.0.1',
  user: process.env.DB_USER || 'root',
  password: process.env.DB_PASSWORD || '123456',
  database: process.env.DB_NAME || 'letou',
  port: process.env.DB_PORT || 3306,
  waitForConnections: true,
  connectionLimit: process.env.DB_POOL_LIMIT || 10,
  queueLimit: 0
};
```

### 环境变量配置

在 `hou/.env` 文件中配置：

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=123456
DB_NAME=letou
DB_PORT=3306
DB_POOL_LIMIT=10
```

### 连接池使用

```javascript
const { query, transaction, pool } = require('./数据库配置.js');

// 简单查询
const rows = await query('SELECT * FROM lottery_results WHERE issue = ?', ['25121']);

// 事务处理
await transaction([
  { sql: 'INSERT INTO lottery_results (...) VALUES (?)', params: [...] },
  { sql: 'UPDATE lottery_results SET ... WHERE ...', params: [...] }
]);
```

## 索引优化

### 现有索引

| 表名 | 索引名 | 字段 | 类型 |
|------|--------|------|------|
| lottery_results | PRIMARY | id | 主键 |
| lottery_results | unique_issue | issue | 唯一索引 |
| backtest_results | PRIMARY | id | 主键 |
| backtest_results | cache_key | cache_key | 唯一索引 |
| qian_qu_shen_du_yu_ce | PRIMARY | id | 主键 |
| qian_qu_shen_du_yu_ce | unique_period_backtest_card | period, backtest_period, card_index | 唯一索引 |
| hou_qu_shen_du_yu_ce | PRIMARY | id | 主键 |
| hou_qu_shen_du_yu_ce | unique_period_backtest_card | period, backtest_period, card_index | 唯一索引 |

### 建议添加的索引

```sql
-- 加速按日期查询
ALTER TABLE lottery_results ADD INDEX idx_draw_date (draw_date);

-- 加速按编号查询
ALTER TABLE lottery_results ADD INDEX idx_bian_hao (bian_hao);

-- 加速回测缓存查询
ALTER TABLE backtest_results ADD INDEX idx_current_period (current_period);
ALTER TABLE backtest_results ADD INDEX idx_backtest_period (backtest_period);

-- 加速深度预测查询
ALTER TABLE qian_qu_shen_du_yu_ce ADD INDEX idx_period (period);
ALTER TABLE hou_qu_shen_du_yu_ce ADD INDEX idx_period (period);
```

## 数据备份策略

### 全量备份

```bash
# 使用 mysqldump 备份
mysqldump -u root -p letou > backup_$(date +%Y%m%d).sql
```

### 定时备份脚本

```bash
#!/bin/bash
# backup.sh
DB_NAME="letou"
DB_USER="root"
DB_PASS="123456"
BACKUP_DIR="/backup/mysql"
DATE=$(date +%Y%m%d_%H%M%S)

mysqldump -u$DB_USER -p$DB_PASS $DB_NAME > $BACKUP_DIR/${DB_NAME}_${DATE}.sql

# 保留最近30天备份
find $BACKUP_DIR -name "${DB_NAME}_*.sql" -mtime +30 -delete
```
